## Findings

### P0 — blocking (all fixed)

1. **Blank product cards.** The catalogue's media contract was incoherent: the pantry
   seeder wrote root-relative paths to files that never existed; endpoints invented their
   own fallbacks, including an SVG the Next.js image optimizer rejects (HTTP 400), so cards
   rendered empty.
   *Impact:* the primary browse flow looked broken for ~10% of the catalogue.*
   *Fix:* one resolver (`App\Services\MediaService`) used by every emitter; on-disk
   verification; raster (never SVG) placeholder; SafeImage degrades on error/empty src on
   the web; `mobile/src/lib/media.ts` rebuilds media URLs against the configured API
   origin; 20 seeded packshots generated in the 600×600 WebP convention (9 remain).
   *Locked by:* `SeededCatalogueMediaTest`, `MediaServiceTest`, `ApiRouteContractTest`.

2. **Rider home/profile and the admin riders page crashed on real data.** Laravel
   `decimal:2` casts serialise as strings ("4.70"); the UI called `.toFixed(1)` on them.
   *Impact:* TypeError → blank screen for every real rider; silent in tests whose fixtures
   used numbers.*
   *Fix:* `formatNumeric`/`Number(...)` coercion at the boundary. *Locked by:*
   `numbers.test.ts`, `RiderHomeScreen` string-rating regression (verified to fail against
   the old expression), `RidersClient.test.tsx`.

3. **Mobile delivery/route maps rendered nothing.** Decimal-string coordinates made the
   bounding-region midpoint `("-29.81" + "-29.83") / 2` → NaN, and native Markers received
   strings the map module rejects.
   *Impact:* the flagship live-tracking feature was invisible on device.*
   *Fix:* coordinates normalised once (`toLatLng`) in RouteMap, LiveDeliveryMap and
   RouteExplorerScreen; `computeBoundingRegion`/`computeBounds` coerce and drop absent
   points instead of letting `Number(null)` become 0,0. *Locked by:*
   `RouteMap.decimal-coords.test.tsx` (renders with the live wire shape).

### P1 — major (fixed)

1. **Icon-only controls without accessible names** (WCAG 4.1.2): admin riders edit button,
   dispatch panel close button. *Fix:* `aria-label` + `title` + focus-visible ring.
2. **Gates with no test behind them.** `GATES.md` G7 (banner editor) had zero coverage;
   its CHECK command could not match any file (vitest filters are regexes, `(admin)` is a
   capture group). *Fix:* a 12-case `BannersClient` suite; all nine gate CHECKs rewritten
   and evidence recorded in `GATES.md`.
3. **Theatre tests.** Six component-level suites asserted on literals they constructed,
   or imported `render` and never called it, citing an "RTL render issue" that is actually
   a missing `await render(...)` (RNTL v14 + React 19 renders asynchronously).
   *Fixed (commits `2b87b1d`, `ad2e222`):* `Stepper`, `RouteMap`,
   `rider-routemap-integration`, `route-explorer-navigation-integration`,
   `HomeCrashPrevention` and `OnboardingScreen` now render their real components with
   live-shaped payloads and drive real interactions. Remaining render-free suites are
   deliberate pure-logic unit tests (lib/, stores/, models, theme tokens) or static
   source scans (accessibility audits).

### P2 — minor

1. **Availability toggle state** was not exposed to AT. *Fixed:* `aria-pressed`, keeping
   the visible text as the accessible name (WCAG 2.5.3).
2. **Banner editor** relies on placeholders for slide fields (plan decision 7 keeps the
   modal). *Open:* add persistent labels to slide inputs if a future pass touches it.
3. **Map tiles** need a live browser check on the target machine (GATES G6). The graceful
   paths are covered: Leaflet tileerror → "Map unavailable", mobile falls back to an info
   card when coordinates are absent.

### P3 — polish

1. Focus-visible rings are inconsistent across older admin controls; apply the
   `focus-visible:ring-2 focus-visible:ring-primary/40` pattern repo-wide in a dedicated pass.
2. Nine remaining seeded packshots (pantry-staples + snacks-treats) still fall back to the
   placeholder until generated.

## Positive findings (preserve these)

- Single destructive-action pattern (`ConfirmDialog`) — no `window.confirm()` anywhere.
- `EmptyState`/`ErrorState` with retry on every data surface, including the no-store dashboard.
- Reduced-motion support (`useReducedMotion`) on animated map markers and transitions.
- The Expo SDK 57 pin is enforced by a postinstall guard and CI — fleet-breaking mistakes
  fail loudly at install time.
- Money is formatted through one `formatMoney`/`formatZar` helper per client in the new code.

## Systemic patterns to avoid repeating

1. **Typed-but-lying wire values.** TypeScript said `number`, Laravel sent strings. Any new
   consumer of a `decimal:*` column must coerce at the boundary — see
   `mobile/src/lib/numbers.ts` for the documented helpers.
2. **Fixtures that flatter the code.** Tests must be built from captured API payloads, not
   idealised numbers; the three P0 bugs all passed their suites.
3. **Per-caller fallbacks.** Whenever two call sites invent the same fallback, extract it
   (MediaService) and test the contract once.
4. **Async test harness rules.** With RNTL v14 + React 19: always `await render(...)`;
   keep at most one fireEvent-driven case per file and put it last (a press leaves the
   async act environment unable to commit later renders in the same file); and never
   import `jest` from `@jest/globals` in a file whose `jest.mock` factories need it,
   because the factories are hoisted above the import.
